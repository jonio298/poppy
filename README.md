# Charles Ross Memorial Slideshow

A full-screen photo slideshow created in loving memory of Charles “Charlie” “Dad” “Poppy” Ross.

- Tap or click **Begin slideshow** to start. The photos are timed evenly across the 22:24 playlist by default.
- **Phones:** swipe left/right to change photos, tap to show or hide the controls.
- **Keyboard:** arrow keys to move, space to pause, **F** for full screen, **E** to edit.

## Editing

Anyone who opens the page can tap the pencil (or **✎ Customize** on the opening slide) to make their own version:

- **Slide:** change the date, add a caption, pick a photo style (plain, polaroid, gold frame, film strip) and a transition, move it earlier/later, or delete it.
- **Show:** change the opening text, default transition and photo style, seconds per photo, and the slow zoom.
- **Theme:** colour presets (or any background/accent colour) and font.
- **All:** jump to any slide, restore deleted ones, download or load a saved version, reset to the original.

Edits save automatically in the viewer's own browser, so each person sees their own version and the original is never changed. Use **Download my version** to back one up or move it to another device.

`photos/thumbs/` holds small previews used by the editor's slide grid.
