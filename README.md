# Charles Ross Memorial Slideshow

A full-screen photo slideshow created in loving memory of Charles “Charlie” “Dad” “Poppy” Ross.

- Click **Begin slideshow** to enter full screen and start automatic playback.
- The 115 photos are timed evenly across the 22:24 playlist, about 11.687 seconds per photo.
- Use the arrow keys to move through the photos, the space bar to pause, and **F** for full screen.
